Мобильное приложение для распознавания и анализа русской речи. Пользователь записывает речь, получает расшифровку и видит допущенные ошибки — хезитации и прочие речевые паттерны — чтобы осознанно работать над своей речью.
Стек
Mobile: React Native
Backend: FastAPI (Python)
ASR: GigaAM v3
Анализ: librosa
Структура
RussianSpeechAnalyzerMVP/
├── SpeechAnalyzer/   # React Native приложение
└── speech-server/    # FastAPI сервер
Как работает

Пользователь записывает речь в приложении
Аудио отправляется на FastAPI-сервер
Сервер распознаёт речь через GigaAM v3 и анализирует хезитации с помощью librosa
Приложение отображает расшифровку и найденные ошибки

Статус
MVP — базовый функционал реализован, проект в активной разработке.
